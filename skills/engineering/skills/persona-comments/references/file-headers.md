# persona-comments: file headers

**Exception to rule 9: an established file-header convention.** When the repo already opens most sibling files in the same directory with a short module header saying what the file is for (a `services/ws/*.ts` directory, for example), a new file's header in that style is not a finding. Check two or three siblings on `origin/main` first. Hold it to the siblings' length, and flag only a header that runs well past them or narrates history.
