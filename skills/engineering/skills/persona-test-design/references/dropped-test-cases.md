# Dropped test cases

10. **Test case dropped when a spec moves or splits (Change Requested for H, Nit for M).** The diff deletes a test case. Match each deleted case to a case in the diff, or on main, that proves the same behaviour. Read the assertion, not only the name. Report each deleted case with no match. Name the behaviour it proved and the file that now holds the rest of the old spec. A case whose behaviour the diff also deletes is not a finding.
