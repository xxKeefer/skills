# no-ai-attribution

A `PreToolUse` hook on `Bash` that denies a `git commit` whose message credits an AI tool. The
agent gets the reason, removes the line, and commits again.

It blocks a message line that matches one of these, case-insensitive:

- `Co-Authored-By:` followed by an AI tool name, such as Claude, Copilot, ChatGPT, Codex, Gemini,
  Cursor, Aider, or Devin
- `Generated with` or `Generated by` followed by an AI tool name
- `noreply@anthropic.com`

A `Co-Authored-By:` line for a person passes.

## Files

| File | Purpose |
|------|---------|
| `no_ai_attribution.py` | The hook. Reads the tool call on stdin, prints a deny decision or nothing on stdout. |
| `no_ai_attribution_test.py` | Test suite. `python3 no_ai_attribution_test.py` exits non-zero on failure. |
| `SKILL.md` | The `setup-no-ai-attribution` installer. Copies the hook and wires it, global or per project. |

## Wiring

Run `/setup-no-ai-attribution` from the `utility` plugin. To do it by hand, copy
`no_ai_attribution.py` to `~/.claude/hooks/no-ai-attribution/` and add this under
`hooks.PreToolUse` in `~/.claude/settings.json`:

```json
{
  "matcher": "Bash",
  "hooks": [{ "type": "command", "command": "python3 ~/.claude/hooks/no-ai-attribution/no_ai_attribution.py" }]
}
```

## Behaviour

- **What it reads.** The command text, which holds each `-m` message and each heredoc body, and
  the file that `-F <file>` or `--file=<file>` names, relative to the session folder.
- **When it fires.** Only on a `git commit`, with or without global options such as `-C <path>`.
  A `git log --grep` or an `echo` of the same text passes.
- **Fail mode.** Fail-open. Input that is not JSON, or a message file it cannot read, allows the
  call.
- **Limits.** It sees only commits that the agent makes through the Bash tool. A commit typed in a
  terminal, or a message written in an editor, does not pass through it. `--amend --no-edit` keeps
  the old message unchecked.
