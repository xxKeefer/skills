# Broadsheet config

Copy this file to `~/.claude/broadsheet.md` and fill it in. An argument in the call overrides a line here.

- paper name: The Vault Herald
- accent: any CSS colour for the headings, tags, and a storm. Default: `#8b1e3f` (oxblood)
- window: 7 days
- stale: 90 days. A note outside the journal, inbox, archive, and meta folders with no edit for this long goes on the stale shelf
- archive: 180 days. An archived note this old, with no link from outside the archive, is a delete candidate
